## Analytics (AI check accuracy)

- Mục **Analytics** trên thanh navigation (extension và TS Management web, giữa Checking và Notifications) đo tỉ lệ AI check ticket đúng: với mỗi comment báo cáo do controller đăng (format hiện tại khôi phục mở đầu `Sau khi TS check thì thấy như sau:` theo "Helpdesk comments"; giữ nhận diện báo cáo đã đăng, kể cả format Han Support nếu có, không sửa comment cũ và không tính ACK/chat/mail draft là báo cáo check), Đại tá react trên Helpdesk — 👍 (hoặc ❤️) = AI check đúng, 😢/😭 = chưa đúng; chưa react = chưa đánh giá. ## Feature flow documents (extension and web)

- Every feature of the Chrome extension and the local webs (TS Management web, Hachimi Trace) has one flow document in `docs/flows/`. The file is named `<feature name> (<what the feature is for>).md`, for example `chat-bot-speech (đọc báo cáo và câu trả lời thành tiếng).md`.
- The document lets an agent understand the feature without reading its code. It states the purpose, how the user triggers it, the flow step by step from the interface to the server or services and back, the files and functions involved with the role of each, the data it stores and where, the settings and permissions it needs, its limits, and how to test it. It is written in Vietnamese and holds no token or secret.
- Before working on a feature, an agent reads its flow document first. It opens the code only for the part it has to add, change or remove.
- Every upgrade, fix or new feature updates the flow document in the same task. A new feature gets a new file. A changed feature has the affected steps rewritten so the document describes the current flow, and a dated line is added to a short "Thay đổi" list at the end. A removed feature is marked as removed with the date; the file itself is deleted only with the user's approval.
- A feature that has no flow document yet gets one from the agent that next touches it, before that task ends.
- A task on extension or web code is not finished until its flow document matches the code. The completion report names the flow file that was written or updated.
