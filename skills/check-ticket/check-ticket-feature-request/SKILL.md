# Feature request ticket

Use the [shared workflow](../SKILL.md). Maximum **5 minutes** for this branch.

Read the merchant's request and Elite findings. Explain:

- Requested capability and concrete use case.
- Whether it is currently supported, has a supported workaround, or needs development.
- Feasibility and the evidence/limitations behind that assessment.
- Next step for TS, BA or Dev, including missing requirements when relevant.

Do not promise a release date or roadmap commitment. Do not send an escalation message; recommend it in the comment. On failure/deadline synthesize only the saved Elite result, preserving uncertainty.
