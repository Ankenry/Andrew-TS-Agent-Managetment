# Question ticket

Use the [shared workflow](../SKILL.md). Maximum **5 minutes** for this branch, as approved by the user.

Use ticket context and Elite findings to explain the merchant's question, the direct answer, any practical configuration steps, missing information, and the next support step. Do not make unrelated storefront changes or contact the merchant. On failure/deadline synthesize the Elite result only. The automatic controller posts the resulting comment; manual requests remain preview-only unless posting is requested.
